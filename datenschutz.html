Datenschutzerklärung für Cloud-sync

Stand: 17. Oktober 2026

Verantwortlicher

Ronny Besser, E-Mail: besser9898@googlemail.com

Zweck

Cloud-sync ist ein privates Tool, das nur Ronny Besser für seine eigenen Konten nutzt. Es liest Termine aus seinen iCloud-Kalendern und schreibt sie in eigene Kalender seines Google-Kontos.

Zugriff auf Google-Nutzerdaten

  • Genutzt wird nur die Google Calendar API (Berechtigung auth/calendar).
  • Das Tool legt eigene Kalender an und erstellt, ändert und löscht darin Termine, die es selbst angelegt hat. Andere Kalender werden nur aufgelistet, aber nicht verändert.
  • Für die Anmeldung wird ein OAuth-Token auf Ronnys eigenem Server gespeichert. Der Server ist nicht öffentlich erreichbar.

Weitergabe und Speicherung

Daten werden nicht an Dritte weitergegeben, nicht verkauft und nicht für Werbung oder für das Training von KI-Modellen genutzt. Gespeichert werden nur technische Zuordnungsdaten (Termin-Kennungen, Prüfsummen, Kalender-IDs) und der Status des letzten Laufs. Bei Problemen kommt eine Push-Nachricht über ntfy.sh an Ronnys Handy. Sie enthält nur Status- und Fehlerhinweise.

Die Nutzung von Daten, die über Google-APIs empfangen werden, hält sich an die Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Widerruf und Löschung

Der Zugriff lässt sich jederzeit unter myaccount.google.com/permissions widerrufen. Wird das Tool gelöscht, werden auch Token und Zuordnungsdaten gelöscht.
